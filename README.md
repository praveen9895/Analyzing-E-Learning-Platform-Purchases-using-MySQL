📊 **Analyzing E-Learning Platform Purchases Using MySQL**
📌 **Project Overview**

This project focuses on analyzing purchase data from an E-Learning Platform using MySQL.
The objective is to design a structured database, insert meaningful data, and perform SQL queries to extract business insights related to learners, courses, enrollments, and purchases.

The project demonstrates practical usage of:

-  Database design

-  SQL queries

-  Joins

-  Aggregations

-  Filtering and analysis

🎯 **Objectives**

Create a relational database for an e-learning platform

Store learner, course, and purchase information

Analyze learner behavior and course performance

Generate insights using SQL queries

Apply real-world business logic using MySQL

🛠️ **Technologies Used**

Database: MySQL

Tool: MySQL Workbench

Language: SQL


🔍 **Key SQL Concepts Used**

-  SELECT, WHERE, ORDER BY

-  INNER JOIN, LEFT JOIN

-  GROUP BY, HAVING

-  Aggregate functions (COUNT, SUM, AVG)

-  Subqueries

-  Foreign key relationships

📊 **Insights from E-Learning Platform Purchase Analysis**
🔍 **Descriptive Insights (What happened?)**

Total Learner Base

-  The platform has a steadily growing learner base, indicating increased adoption of online education.

Course Purchase Distribution

-  A small number of courses contribute to a large share of total purchases, showing a skewed demand pattern.

Revenue Contribution

-  Higher-priced courses generate significant revenue even with fewer enrollments, while lower-priced courses drive volume.

Repeat Learners

-  Several learners have purchased more than one course, indicating strong user engagement and satisfaction.

📈 **Diagnostic Insights (Why did it happen?)**

Popular Course Categories

-  Courses in technical and professional domains attract more enrollments due to higher career relevance.

Pricing Impact

-  Courses priced moderately show higher enrollment compared to premium-priced courses.

Learner Behavior

-  Learners who register earlier are more likely to purchase multiple courses, suggesting trust builds over time.

🔮 **Predictive Insights (What is likely to happen?)**

Future Course Demand

-  Courses with consistent monthly purchases are likely to remain in high demand.

Revenue Growth Trend

-  If current purchase trends continue, overall platform revenue is expected to grow steadily.

Repeat Purchase Probability

-  Learners who purchase one course are likely to enroll in additional courses within the same category.

🧠 **Prescriptive Insights (What should be done?)**

Bundle Popular Courses

-  Combining top-selling courses into bundles can increase revenue and learner retention.

Targeted Marketing

-  Promote premium courses to repeat learners who already show high engagement.

Dynamic Pricing Strategy

-  Introduce discounts on high-priced courses during peak enrollment periods.

Course Development Focus

-  Invest more in creating courses similar to top-performing ones.

✅ **Conclusion**

This project demonstrates how SQL can be effectively used to analyze real-world business data.
By applying relational database concepts and analytical queries, meaningful insights are derived that support data-driven decisions in an e-learning environment.
